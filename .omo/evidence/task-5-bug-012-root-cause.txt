2. ATTRIBUTION
--------------------------------------------------------------------------------
ATTRIBUTION: BUG-RTL-SOC-012 root cause is an RTL-wrapper × driver-
programming-model interaction — the wrapper's latched MXU DIM1 override
(rtl/wrapper/mxu_soc_wrapper.v:207/221/719-721, introduced by 8dd5dbe
"fix(rtl/wrapper): correct M=1 multi-tile broadcast/store-out count (P9
branch B)") forces a 256B-per-row store-out geometry driven by the driver's
pad-to-64 DIM1 (sim/cocotb_bridge.py:2100-2107), so op05's M=32/N=2 result is
written as 32 rows at a 256B stride and the test's dense 256B readback
(sim/cocotb_bridge.py:2424-2438 via _sram_backdoor_read :591-592) sees only
row 0 → 62/64 INT32 mismatches, first @ byte[8]; the two original hypotheses
are refuted — stale-golden by the task-3 live-golden isolated repro
(ISO-VERDICT: repro-fail-identical) and drain-only-row by controller
drain-all-rows logic (rtl/mxu/controller.v:277-308) plus task-4 Phase A
full-row geometry (H-STRIDE-EMPIRICAL: confirmed); firmware path unaffected
because it programs DIM1=real N (firmware/npu_firmware.c:273). Status remains
Open (investigation-only, user decision); fix directions recorded: (1)
driver-side DIM1=actual N (preferred, H-TRIGGER-DIM1: actual-N-sufficient),
(2) wrapper-side WRP_DIM_N priority over dim1_n (product RTL, full regression
required).

Divergence inventory (which offsets diverged from the oracle, grouped):
  MXU      (1):  w-store CMD +0x04 — real readback 0x00000000 (CMD is write-only
                 pulse in mmio_if; model w-store expects 0x42). All other 10
                 offsets conform (reset 0, rw overwrite, STATUS hostile-immune).
  SFU      (1):  w-store CMD +0x04 — same write-only pulse semantics.
  VECTOR   (1):  w-store CMD +0x04 — same write-only pulse semantics.
  DMA      (0):  fully conforms to the model oracle (14/14 offsets; even CMD
                 w-store readback 0x42 matches — axi_cdma-style reg file stores it).
  PCIE    (27):  real pcie_ep_wrapper layout differs from the Func Model factory
                 layout used by the oracle:
                 - reset: +0x00 got 0 (oracle 0x0001 COMPLETER_ID), +0x04 got 0
                   (oracle 3 MAX_PAYLOAD_SIZE), +0x0C/+0x10/+0x14/+0x18 return
                   RO BAR constants 0x2000_0000/0xFFC0_0000/0x8000_0000/
                   0x8000_0000, +0x1C/+0x20 got 0, +0x24 UNMAPPED (pslverr=1,
                   logged [INFO] pslverr=1) — oracle had BAR0_BASE@0x18=0x2000_0000,
                   BAR0_MASK@0x1C=0x003F_FFFF, BAR1_BASE@0x20=0x8000_0000,
                   BAR1_MASK@0x24=0x7FFF_FFFF;
                 - access: PCIE_CTRL write 0x3 reads back 0x6 (max_payload_size
                   field sits at bits[3:1], bit[0]=enable — bit-layout divergence
                   vs oracle's 32-bit store); BAR regs are RO (writes ignored);
                   MSIX_CTRL/IRQ_CTRL are field-masked (0x3 -> readback 1);
                   +0x24 unmapped -> pslverr.
  DOORBELL (6):  +0x08 HOST_HEAD and +0x0C NPU_TAIL are RW in real RTL (hostile
                 write 0xFFFFFFFF stored, readback 0xFFFFFFFF — oracle expects
                 RO unchanged 0); +0x10 LAST_STATUS and +0x14 COMPLETION_STATUS
                 do not exist in real doorbell (reads 0, writes ignored —
                 oracle expects rw). +0x00 HOST_TAIL and +0x04 NPU_HEAD conform.
  INTC     (4):  reset THRESHOLD +0x08 = 1 (oracle 0 — real RTL reset default);
                 r-hostile PENDING +0x00 readback 0x00000020 (real PENDING is a
                 live 8-bit sticky status register driven by real irq sources —

                 stimulus; oracle expects static RO 0); w1c ACK +0x0C reads 0
                 (real ACK is clear-only, not readable — oracle w1c expects
                 16-bit seeded readback 0xFF0F/0xFFFF). ENABLE/THRESHOLD rw

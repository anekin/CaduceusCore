NEW SCRIPT APIs
--------------------------------------------------------------------------------
scripts/gen_evidence_provenance.py  (SHA-256 provenance block generator)
    Usage: python3 scripts/gen_evidence_provenance.py --run-id ID --simv P
           --flist P --driver P --firmware P --golden P --checkpoint P [--out F]
    Emits a stable-key header block (provenance_begin .. provenance_end) with:
      provenance_run_id / provenance_timestamp
      provenance_git_commit + provenance_git_dirty (git status --porcelain count
        + up to 50 porcelain lines)
      provenance_simv_path + provenance_simv_sha256
      provenance_flist_path + provenance_flist_sha256
      provenance_driver_path + provenance_driver_sha256
      provenance_firmware_path + provenance_firmware_sha256
      provenance_golden_path + provenance_golden_sha256   (dir -> deterministic
        aggregate over sorted (relpath, file-sha256) pairs)
      provenance_checkpoint_path + provenance_checkpoint_sha256
      provenance_tool_versions (vcs -ID, cocotb, python, riscv64-unknown-elf-gcc,
        GNU timeout, spike; each best-effort -> 'unavailable')
    Missing artifacts record '<key>=missing' honestly; block is always emitted.
    All digests are SHA-256. --help works. pyflakes clean.

scripts/check_evidence_provenance.py  (Metis C3 executable definition)
    Usage: python3 scripts/check_evidence_provenance.py [--strict] [--skip CLASS] EVIDENCE
    Verifies: (1) complete provenance_begin..provenance_end header present,
    (2) every recorded artifact hash recomputed and matched against the file
    currently on disk, (3) recorded git commit == current HEAD.
    Exit codes: 0 VERIFIED / 1 REJECTED (missing header, truncated, commit
    mismatch, hash mismatch) / 2 USAGE.
    Verification matrix executed:
      fresh evidence (mock build)          -> exit 0  VERIFIED
      forged (simv tampered after write)   -> exit 1  REJECTED (sha mismatch)
      truncated (provenance_end removed)   -> exit 1  REJECTED
      no header at all                     -> exit 1  REJECTED
      tamper reverted                      -> exit 0  VERIFIED again
      real-repo evidence (real simv/flist/driver/firmware/golden/ckpt) -> exit 0

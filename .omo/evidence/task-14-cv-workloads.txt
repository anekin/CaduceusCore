## Host-Only Rubric (Frozen)

host_only = op that does not emit an MMIO command for MXU/SFU/Vector/DMA/NoC/KV.

Host-only ops in CV manifests:
- MobileNetV3-Small: shape, global_avg_pool (10), mul (9), add (6), concat, reshape = 28 entries
- ResNet50: none (all 105 entries have engine classification; max_pool and avg_pool emit SFU cycles)
- YOLOv8n: max_pool (3, SPPF), upsample (2), concat (4) = 9 entries

All host-only entries have:
  engine: null
  op: null
  host_only: true
  shape: {}

All non-host entries have:
  engine: "mxu" or "sfu"
  op: "mmul" (for mxu) or "silu" (for sfu)
  shape: {M, K, N} for mxu, {elements} for sfu

1. MECHANISM CHAIN (all file:line verified against live HEAD source)
------------------------------------------------------------------------
Hypothesis (H-STRIDE): wrapper dim1_n (latched from MXU DIM1 MMIO write,
reset default 64) overrides WRP_DIM_N=2, forcing row_bytes_per_store=256B;
driver pads DIM1 to 64; firmware uses real N; the 256B readback window
sees only row 0's real data + zero padding → 62/64 signature.

Chain closure: driver writes DIM1=64 (padded) → wrapper latches dim1_n=64
(:221) → row_bytes_per_store=256B (:720) → 32 rows written at out_base+r*256.
Driver then reads 256 contiguous bytes (:2436) = exactly row 0's 256B window
(2 real words + 62 zero-padding words). Golden comparison expects 64 dense
words (32 rows × 2 cols) → rows 1-31 absent → 62/64 INT32 mismatches,
first mismatch @ byte[8] (actual 0x00 vs golden 0xD0). Exact signature
reproduction of .omo/evidence/task-14-blk0-investigation.txt:58.

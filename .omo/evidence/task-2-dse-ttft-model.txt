- `simulate_layer(config, batch_m=None)` regenerates the trace via

- `evaluate_config` LLM path computes `ttft_ms` (0.0 for CV mode) and emits it in
  `config["ttft_ms"]`; JSON output adds top-level `ttft_ms` per result (non-CV).
- CLI `--batch-m`: `type=int` (no choices) + validation `>= 1`.
- Quick sweep dims now include (64, 64) so Block 64×64 (RTL Phase 1 config) is evaluated.

=== ROOT CAUSE ANALYSIS ===
The original bug (docs/bugs/bugs-soc-rtl.md:56-66) was:
  "Unable to load extlib 'npu_mmio_plugin.so':
   /lib64/libc.so.6: version 'GLIBC_2.32' not found"

This was caused by npu_mmio_plugin.so being compiled on a machine with
newer GLIBC (2.32) while sz0001 only has GLIBC 2.17. The fix — rebuilding
on sz0001 with devtoolset-9 — resolves this ABI mismatch.

The remaining mmul_smoke failure (BrokenPipeError after socket connect)
is a pre-existing firmware/bridge protocol issue unrelated to the plugin
ABI. The plugin now loads correctly and connects to the bridge.

## What was implemented
Doorbell-path MMUL regression (SCALE_ADDR != 0) with non-trivial random FP32
per-block scales:
  - M=1, K=256, N=128 -> num_blocks = (256+127)//128 = 2 (multi-block scale path)
  - scale buffer written in the FM bridge-reader layout [ceil(K/128)][N] fp32
    contiguous (mmio_bridge.py:248-252), NOT the firmware per-64 layout
  - scales = rng.uniform(0.5, 1.5) fp32, seed 20260823
  - descriptor via host_write_descriptor (scale_addr=0x8011_0000, scale_size=1024)
  - dispatched via host_write_command(OpCode.MMUL) -> firmware run_loop
  - output compared vs GoldenMXU.matmul_int4_per_block(group_size=128)
    with rtol=1e-5, atol=1e-5
  - failure-injection variant writes the scale region as FP16 bytes (half
    length, F3 PERF-bug shape) and asserts the golden comparison FAILS
    (not np.allclose), so a vacuous comparison regression is caught in-suite.

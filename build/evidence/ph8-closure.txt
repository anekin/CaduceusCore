1. SCOPE STATEMENT
======================================================================

Phase 8 fixed data-layout and ring buffer issues in the Python
performance-test harness (sim/perf_tests.py). The PERF path writes
activations and weights to DRAM for the Ibex firmware to load and
dispatch; the harness was writing raw row-major data, but the MXU
preload sequencer (via mxu_soc_wrapper) requires K-vector tile-major
layout.  This caused MXU output to be all-zeros in many test cases.

The fix is purely in the Python harness — no RTL Verilog, firmware C,
or cocotb_bridge.py files were modified.  Multi-tile M=1 bugs that
remain are in the firmware/RTL domain and therefore out of scope for
Phase 8.

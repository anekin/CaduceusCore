## 6. Baseline Contradiction Resolution

### The Contradiction

| Source | pytest | SFU | Vector |
|--------|--------|-----|--------|
| **README.md** | 210 passed | 319/319 | 63/63 |
| **Plan (success criteria)** | >=700 | 526/537 | 64/64 |
| **Phase 5 actual (Jul 10)** | 700 P, 9 F | 526/537 | 64/64 |
| **Phase 6 actual (Jul 19)** | 735 P, 8 F | 526/537 | 64/64 |

### Root Cause Analysis

The README numbers are **stale** — they reflect the test suite size from Phase 1-2 (late 2025/early 2026), before the full expansion to Phase 5:

| Phase | Date | pytest | SFU scenarios | Vector scenarios |
|-------|------|--------|---------------|-----------------|
| Phase 1-2 (MXU + SFU/Vector initial) | 2025 Q4 | ~210 | 319 | 63 |
| Phase 3-4 (SoC integration) | 2026 Q1-Q2 | ~500+ | 319→500+ | 63→64 |
| Phase 5 (W1-W4 batch) | 2026 Jun-Jul | 709 (700P+9F) | 537 | 64 |

The plan's success criteria table was written with Phase 5 actuals (Jul 10 regression results) as the baseline:

- **pytest >=700**: Reads "700 or more passing tests." The Phase 5 count was exactly 700. ✓
- **SFU 526/537**: Reads "526 passing out of 537." This was the Phase 5 actual after expanding from the initial 319 scenarios. ✓  
- **Vector 64/64**: Reads "64 passing out of 64." Phase 5 added 1 more Vector scenario (64 vs 63). ✓

### Resolution

**The plan numbers (pytest >=700, SFU 526/537, Vector 64/64) are correct and authoritative.** The README numbers are outdated and should be updated. Phase 6 confirms all plan numbers:

- pytest: **735 passed** ≥ 700 ✓
- SFU: **526/537** = 526/537 ✓  
- Vector: **64/64** = 64/64 ✓
- FM-SOC: **33/33** ✓ (consistent in both sources)
- MXU: **9/9** ✓ (consistent in both sources)

BACKGROUND
----------
The RTL SoC has two independent readback paths:
  1. bk (backdoor): VPI-based direct SRAM/DRAM access via CocotbBridge
  2. pcie: PCIe TLP read/write through the PCIe EP → AXI crossbar → DRAM

Dual-path verification proves that both paths produce correct data for the
same compute results, and that the PCIe path is genuinely exercised (not a
no-op that silently returns correct-looking data).

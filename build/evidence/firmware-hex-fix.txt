--- Root Cause ---
The hex file was valid all along. The linker script (firmware/link.ld)
reserves 0x00-0x7f for a RISC-V vectored trap table (FILL(0x00)), placing
_start at 0x80. The Ibex reset vector is at boot_addr + 0x80. The test
asserted at 0x0, missing the 0x80 offset. Fix: test now checks 0x0 for
trap table zeros and 0x80 for first non-zero instruction.

# rtl/ — Verilog design + testbenches

## OVERVIEW
64×64 INT4×INT8 broadcast MAC (MXU) + SFU (7 FP16 ops) + Vector engine; SoC integration (AXI crossbar M=7, APB decoder, SRAM ctrl, doorbell, INTC, boot ROM); module-level and cocotb testbenches. Vendored dirs (cpu/ibex/, ip/verilog-axi/, ip/verilog-pcie/) are NEVER edited.

## STRUCTURE
```
rtl/
├── mxu/ sfu/ vector/ intc/   # engine RTL (own code): *_top.v, *_hw.v pipelines, PE/MAC array
├── soc/     # caduceus_soc_top.v:41 (top), axi_crossbar, apb_decoder, sram_ctrl, boot_rom, doorbell
├── wrapper/ # *_soc_wrapper.v APB+AXI adapters; MMIO layout in header comment tables
├── ip/      # own: dma_wrapper.v, pcie_dma_wrapper.v, dram_model.v; vendored: verilog-*/
├── cpu/     # ibex_wrapper.v (own) + ibex/ (vendored)
├── tb/      # module TBs (self-checking) + cocotb shells (tb_soc, tb_soc_ibex, tb_soc_spike)
└── test_vectors/  # generated $readmemh scenarios (2591 files: hex/json/txt/npz)
```

## WHERE TO LOOK
| Task | Location |
|------|----------|
| Full-chip integration | `soc/caduceus_soc_top.v` (params :42-44, CROSSBAR_MASTERS=7) |
| Crossbar arbitration | `soc/axi_crossbar.v` + `tb/axi_crossbar_fairness_tb.sv` |
| Wrapper register layout | `wrapper/mxu_soc_wrapper.v` header table (:16-21) |
| Test vector format | `test_vectors/<engine>/<scenario>/` manifest.json + hex files |
| Boot flow | `soc/boot_rom.v` ($readmemh via +BOOTROM_HEX, :36-38) |

## CONVENTIONS
- Flist-only compilation (`soc/soc.flist`); `ibex.flist` MUST be first (contains ibex_pkg.sv); flists are sectioned with `# ── Section ──` comments.
- `$readmemh` via plusarg with hardcoded fallback; vectors generated by `scripts/gen_*_vectors.py` from the Func Model golden.
- Module naming: `_top` engine top, `_hw` SFU pipeline stage, `_soc_wrapper` integration adapter; snake_case matching filename.
- MMIO registers documented as `Offset Name Access Description` header tables; 4KB window, addr[11:0] via apb_to_mmio.
- TB comparison: tb_mxu internal INT32 bit-exact; tb_sfu `$system` call to scripts/compare_sfu.py (abs_tol=2e-3, rel_tol=1e-2); tb_vector internal self-check.
- VCS flags: `-full64 -sverilog -debug_access+all -timescale=1ns/1ps`; simv run from repo parent.

## ANTI-PATTERNS
- NEVER edit vendored `verilog-pcie`/`verilog-axi`/`ibex` sources — extend wrappers instead (stated in pcie_dma_wrapper.v:19, dma_wrapper.v:30).
- Wrappers must NOT modify engine `*_top` internals (mxu_soc_wrapper.v:32, sfu_soc_wrapper.v:17, vector_soc_wrapper.v:37).
- Module-level wrapper TBs must NOT instantiate crossbar/DRAM/CPU/SoC components (tb_*_wrapper.v headers).
- No glob compilation — keep flists explicit and sectioned.
- Verification plans must not touch rtl/ product code (only rtl/tb/ whitelisted by fm_hardening_f4_scope_gate.sh).

## NOTES
- README says M=6 crossbar, but `CROSSBAR_MASTERS=7` (6 engines + PCIe TLP port) — trust the RTL parameter.
- SFU HW sub-op codes (sfu_top.v:60-66): softmax=0, layernorm=1, gelu=2, relu=3, silu=4, rope=5, rmsnorm=6.
- Many TBs exist in duplicated variants across tb/ and soc/ and ip/ (e.g., dram_model_tb, apb_decoder_tb, pcie_ep_tb) — check both locations before assuming one is canonical.
- `rtl/test_vectors/` is generated data; commit with `git add -f` if evidence needs it.
